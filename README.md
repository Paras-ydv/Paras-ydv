## Selected work

**[TestPilot AI](https://github.com/Paras-ydv/TestPilot_AI)** — an autonomous agent that tests web applications from live runtime behaviour, with no predefined scripts. An 8-node LangGraph pipeline drives Playwright over discovered UI, network and console activity, with a Qdrant vector store that carries what it learned across runs. Ships as a VS Code extension.
<sub>`TypeScript` · `LangGraph` · `Playwright` · `Qdrant`</sub>

**[wifi_rtt_measurement](https://github.com/Paras-ydv/wifi_rtt_measurement)** — research-grade Android app for device-to-device Wi-Fi RTT ranging. Receiver/Publisher roles, live statistics, distance graphs, CSV export.
<sub>`Kotlin` · `Android SDK` · `IEEE 802.11mc`</sub>
